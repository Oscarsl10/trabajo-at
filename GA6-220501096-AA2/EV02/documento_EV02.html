GA6-220501096-AA2-EV02 · Proyecto TiendaFácil


Octubre de 2026

1. Introducción

El proyecto formativo es TiendaFácil, un sistema de gestión de inventario y ventas para una tienda de barrio. Requiere controlar productos, proveedores, clientes, usuarios del sistema y las ventas realizadas. Este documento describe la estructura de la base de datos tienda_db (MySQL 8.0), sus atributos, tipos de datos y restricciones.

2. Objetivo

Definir la estructura de la base de datos del proyecto determinando tipos de datos, llaves primarias, llaves foráneas y demás restricciones que garanticen la integridad de la información.

3. Modelo entidad-relación

El diseño se representa en diagrama_entidad_relacion.svg y puede abrirse/reconstruirse en MySQL Workbench con Database → Reverse Engineer sobre el script de EV03 (genera el diagrama EER y el archivo .mwb).

6. Conclusiones

Las llaves primarias, foráneas, UNIQUE, CHECK y DEFAULT protegen la integridad de los datos. El script ejecutable se entrega en EV03.
