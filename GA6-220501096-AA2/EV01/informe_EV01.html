1. Introducción

El lenguaje SQL se divide en sentencias DDL (definición de estructuras: CREATE, ALTER, DROP) y DML (manipulación de datos: INSERT, UPDATE, DELETE, SELECT). Este informe documenta las sentencias empleadas para resolver el taller de la tabla «libreta», ejecutadas en MySQL 8.0.

2. Objetivo

Aplicar sentencias DDL y DML de SQL para crear, consultar, poblar y actualizar una tabla, verificando cada paso con su resultado.

3. Desarrollo del taller

Punto 1. Crear la tabla «libreta»

CREATE TABLE libreta (
  nombre    VARCHAR(20),
  domicilio VARCHAR(30),
  telefono  VARCHAR(11)
);

Punto 2. Visualizar las tablas existentes

SHOW TABLES;

Resultado obtenido en MySQL 8.0:

+----------------------+
| Tables_in_taller_sql |
+----------------------+
| libreta              |
+----------------------+

Punto 3. Estructura de la tabla

DESCRIBE libreta;

Resultado obtenido en MySQL 8.0:

+-----------+-------------+------+-----+---------+-------+
| Field     | Type        | Null | Key | Default | Extra |
+-----------+-------------+------+-----+---------+-------+
| nombre    | varchar(20) | YES  |     | NULL    |       |
| domicilio | varchar(30) | YES  |     | NULL    |       |
| telefono  | varchar(11) | YES  |     | NULL    |       |
+-----------+-------------+------+-----+---------+-------+

Punto 4. Ingresar los registros

INSERT INTO libreta (nombre, domicilio, telefono) VALUES ('Alberto Mores', 'Colon 123', '4234567');
INSERT INTO libreta (nombre, domicilio, telefono) VALUES ('Juan Torres', 'Avellaneda 135', '4458787');

Punto 5. Mostrar todos los registros

SELECT * FROM libreta;

Resultado obtenido en MySQL 8.0:

+---------------+----------------+----------+
| nombre        | domicilio      | telefono |
+---------------+----------------+----------+
| Alberto Mores | Colon 123      | 4234567  |
| Juan Torres   | Avellaneda 135 | 4458787  |
+---------------+----------------+----------+

Punto 6. Actualizar los datos insertados

UPDATE libreta SET telefono = '4234000' WHERE nombre = 'Alberto Mores';
UPDATE libreta SET domicilio = 'Avellaneda 200', telefono = '4458000' WHERE nombre = 'Juan Torres';
SELECT * FROM libreta;

Resultado obtenido en MySQL 8.0:

+---------------+----------------+----------+
| nombre        | domicilio      | telefono |
+---------------+----------------+----------+
| Alberto Mores | Colon 123      | 4234000  |
| Juan Torres   | Avellaneda 200 | 4458000  |
+---------------+----------------+----------+

Punto 7. Insertar 5 registros más

INSERT INTO libreta (nombre, domicilio, telefono) VALUES
  ('Maria Lopez',   'Sarmiento 450',  '4321122'),
  ('Carlos Gomez',  'Belgrano 78',    '4335566'),
  ('Ana Fernandez', 'Rivadavia 910',  '4347788'),
  ('Luis Perez',    'San Martin 25',  '4359900'),
  ('Laura Diaz',    'Mitre 666',      '4361234');

Punto 8. Contar los registros

SELECT COUNT(*) AS total_registros FROM libreta;

Resultado obtenido en MySQL 8.0:

+-----------------+
| total_registros |
+-----------------+
|               7 |
+-----------------+

La tabla contiene 7 registros: los 2 iniciales y los 5 adicionales.

4. Conclusiones

Se ejecutaron correctamente las sentencias DDL (CREATE TABLE, SHOW, DESCRIBE) y DML (INSERT, SELECT, UPDATE, COUNT) del taller. El script completo está en libreta.sql.
